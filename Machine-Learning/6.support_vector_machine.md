# Support Vector Machine (SVM)

- **Supervised** ML algorithm, mainly for classification (also adaptable to regression via SVR).
- Developed by **Vladimir N.Vapnik**.
- Goal: find the **optimal hyperplan** that best separates classes in N-dimensional space.

## Key Terms

| Term                | Meaning                                                              |
| ------------------- | -------------------------------------------------------------------- |
| **Hyperplane**      | Decision boundary separating classes (line in 2D, plane in 3D)       |
| **Support Vectors** | Data points closest to the hyperplane; they define it                |
| **Margin**          | Distance between the hyperplane and the nearest points of each class |
| **Maximum Margin**  | SVM picks the hyperplane with the widest margin                      |

## Graph: Hyperplane & Margin (2D)

```
  y
  ↑
  │   ○       ○        ╲ ┆         ┆ ╲   ← margin boundary (+)
  │       ○      ○      ╲┆         ┆  ╲
  │    ○       ○ ◉       ╲  ← support vector
  │        ○       ╲      ╲
  │                 ╲  ━━━━ ╲   ← HYPERPLANE (w·x + b = 0)
  │                  ╲  ╲    ╲
  │              ▲ ◈   ╲  ╲    ╲
  │          ▲      ▲    ╲  ╲
  │       ▲     ▲        ╲  ╲
  │           ▲    ▲
  └─────────────────────────────→ x

  ○ = Class +1     ▲ = Class -1
  ◉ ◈ = Support Vectors
```

Simpler view of the margin:

```
   Class +1            │←── margin ──→│            Class -1
                       │              │
   ○   ○    ○  ┆╌╌╌╌╌╌┆╌╌╌╌╌╌┃╌╌╌╌╌╌┆  ▲    ▲   ▲
     ○    ○   ◉┆      ┆      ┃      ┆◈  ▲     ▲
   ○    ○      ┆      ┆      ┃      ┆     ▲
                  w·x+b=+1  w·x+b=0  w·x+b=-1
                            (hyperplane)
```

## How It Works

1. Plot data in N-dimensional space
2. Find hyperplane: **w · x + b = 0**
3. **Maximize margin** = 2 / ‖w‖
4. Only **support vectors** affect the boundary; other points are ignored

## Types

- **Linear SVM**: data is linearly separable
- **Non-linear SVM**: uses the **kernel trick** to map data into higher dimensions

```
 Not separable in 2D        Kernel map        Separable in 3D
                            ────────→
   ○ ▲ ▲ ○                                      ▲ ▲ ▲   ← lifted up
   ▲ ○ ○ ▲                                    ─────────── plane
   ○ ▲ ▲ ○                                      ○ ○ ○
```

## Common Kernels

| Kernel             | Use case                             |
| ------------------ | ------------------------------------ |
| **Linear**         | Linearly separable data              |
| **Polynomial**     | Curved boundaries                    |
| **RBF (Gaussian)** | Default for complex, non-linear data |
| **Sigmoid**        | Neural-network-like behavior         |

## Hard vs Soft Margin

- **Hard margin**: no misclassification allowed (sensitive to outliers)
- **Soft margin**: allows some errors, controlled by parameter **C**
  - High **C** → narrow margin, fewer errors (risk of overfitting)
  - Low **C** → wide margin, more errors (risk of underfitting)

## Pros & Cons

| Pros                                         | Cons                                     |
| -------------------------------------------- | ---------------------------------------- |
| Effective in high dimensions                 | Slow on very large datasets              |
| Memory efficient (uses only support vectors) | Sensitive to kernel and parameter choice |
| Works well with clear margin of separation   | Poor with noisy / overlapping classes    |
| Versatile via kernels                        | No direct probability output             |

## Applications

- Text & spam classification
- Image recognition
- Face detection
- Bioinformatics (gene/protein classification)
- Handwriting recognition
