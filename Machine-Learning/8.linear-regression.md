# Linear Regression

A supervised learning algorithm that models the relationship between input features & a continuous target by fitting a straight line (or hyperplane).

```
ŷ = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
```

- ŷ predicted value
- w weights (coefficients)
- b bias (intercept)

## Intuition

```
  y
  │                    ●
  │               ●  ╱
  │            ╱  ●
  │       ●  ╱
  │     ╱ ●
  │  ●╱
  │ ╱
  └──────────────────── x
    best-fit line minimizes
    the distance to all points
```

## Loss Function: MSE

```
MSE = (1/n) Σ (yᵢ − ŷᵢ)²
```

```
  error
    │ ╲               ╱
    │  ╲             ╱
    │   ╲           ╱
    │    ╲_________╱
    │        ▲
    └────────┴──────── w
         minimum
```

squaring penalizes large errors more & keeps the loss convex, so there is one global minimum.

## Two Ways to Solve

| Method           | Formula / Idea       | Best for                      |
| ---------------- | -------------------- | ----------------------------- |
| Normal Equation  | `w = (XᵀX)⁻¹Xᵀy`     | Small datasets, few features  |
| Gradient Descent | `w := w − α · ∂L/∂w` | Large datasets, many features |

**Gradient descent loop:**

```
 ┌──────────────┐
 │ init w, b    │
 └──────┬───────┘
        ▼
 ┌──────────────┐
 │ predict ŷ    │◄────────┐
 └──────┬───────┘         │
        ▼                 │
 ┌──────────────┐         │
 │ compute loss │         │
 └──────┬───────┘         │
        ▼                 │
 ┌──────────────┐         │
 │ update w, b  │─────────┘
 └──────────────┘
   repeat until converged
```

`α` is the learning rate. Too large and it diverges, too small and it crawls.

## Assumptions

1. **Linearity**: the relationship is linear in the parameters
2. **Independence**: errors are independent
3. **Homoscedasticity**: constant error variance
4. **Normality**: residuals are roughly normal
5. **No multicollinearity**: features aren't highly correlated

## Evaluation Metrics

| Metric     | Meaning                                                         |
| ---------- | --------------------------------------------------------------- |
| MAE        | Mean absolute error, robust to outliers                         |
| MSE / RMSE | Penalizes big errors, RMSE is in target units                   |
| R²         | Fraction of variance explained (1 = perfect, 0 = mean baseline) |

## 󰗖 Variants

- **Multiple LR**: many features
- **Polynomial**: add `x²`, `x³` terms (still linear in weights)
- **Ridge (L2)**: adds `λΣw²`, shrinks weights
- **Lasso (L1)**: adds `λΣ|w|`, drives some weights to zero (feature selection)
- **ElasticNet**: L1 + L2 combined

## Pitfalls

- Sensitive to **outliers**
- **Scale features** when using gradient descent or regularization
- Cannot capture non-linear patterns without feature engineering
- **Overfitting** with many features, so use regularization
