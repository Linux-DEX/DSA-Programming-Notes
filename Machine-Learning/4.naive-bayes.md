# Naive Bayes

- Naive Bayes algorithm is a fast, highly scalable supervised machine learning classification algorithm based on Bayes' Theorem.
- It is primarily used for binary or multi-class text categorization problem, such as spam detection & sentiment analysis.

```
       [ Input Data Vector: X = (x1, x2, ..., xn) ]
                            │
                            ▼
               ┌─────────────────────────┐
               │  Bayes' Theorem + MAP   │
               └────────────┬────────────┘
                            │
            ┌───────────────┴───────────────┐
            ▼                               ▼
     [ Calculate Class 0 ]           [ Calculate Class 1 ]
     P(Y=0) * ∏ P(xi|Y=0)            P(Y=1) * ∏ P(xi|Y=1)
            │                               │
            └───────────────┬───────────────┘
                            ▼
               ┌─────────────────────────┐
               │    ArgMax Comparison    │
               │   Which score is higher?│
               └────────────┬────────────┘
                            │
                            ▼
                [ Final Predicted Class ]
```

### Naive Bayes Classification Formula

$$\hat{y} = \arg\max_y \left[ P(y) \cdot \prod_{i=1}^{n} P(x_i \mid y) \right]$$

#### Component Breakdown

- **$\hat{y}$** ➜ The final predicted class output.
- **$\arg\max_y$** ➜ The decision rule that selects the class $y$ yielding the highest score.
- **$P(y)$** ➜ **Prior Probability** of class $y$ (how common the class is overall).
- **$\prod\_{i=1}^{n}$** ➜ Product operator (multiplies all feature probabilities together).
- **$P(x_i \mid y)$** ➜ **Likelihood** (probability of feature $x_i$ appearing given class $y$).
