# Naive Bayes

- Naive Bayes algorithm is a fast, highly scalable supervised machine learning classification algorithm based on Bayes' Theorem.
- It is primarily used for binary or multi-class text categorization problem, such as spam detection & sentiment analysis.

## Assumption of Naive Bayes

- Feature independence.
- Continuous feature are normally distributed.
- Discrete features have multinomial distributions.
- Features are equally important.
- No missing data.

```
       [ Input Data Vector: X = (x1, x2, ..., xn) ]
                            │
                            ▼
               ┌─────────────────────────┐
               │  Bayes' Theorem + MAP   │
               └────────────┬────────────┘
                            │
            ┌───────────────┴───────────────┐
            ▼                               ▼
     [ Calculate Class 0 ]           [ Calculate Class 1 ]
     P(Y=0) * ∏ P(xi|Y=0)            P(Y=1) * ∏ P(xi|Y=1)
            │                               │
            └───────────────┬───────────────┘
                            ▼
               ┌─────────────────────────┐
               │    ArgMax Comparison    │
               │   Which score is higher?│
               └────────────┬────────────┘
                            │
                            ▼
                [ Final Predicted Class ]
```

### Naive Bayes Classification Formula

$$\hat{y} = \arg\max_y \left[ P(y) \cdot \prod_{i=1}^{n} P(x_i \mid y) \right]$$

#### Component Breakdown

- **$\hat{y}$** ➜ The final predicted class output.
- **$\arg\max_y$** ➜ The decision rule that selects the class $y$ yielding the highest score.
- **$P(y)$** ➜ **Prior Probability** of class $y$ (how common the class is overall).
- **$\prod\_{i=1}^{n}$** ➜ Product operator (multiplies all feature probabilities together).
- **$P(x_i \mid y)$** ➜ **Likelihood** (probability of feature $x_i$ appearing given class $y$).

## Dataset: Weather vs. Playing Tennis

| Day | Outlook  | Humidity | Target: Play? |
| --- | -------- | -------- | ------------- |
| 1   | Sunny    | High     | No            |
| 2   | Sunny    | High     | No            |
| 3   | Overcast | High     | Yes           |
| 4   | Rain     | High     | Yes           |
| 5   | Rain     | Normal   | Yes           |

---

## Explanation & Calculation

We want to predict if we will play tennis given a new day where:

- Outlook = Sunny
- Humidity = High

## Step 1: Calculate Target Prior Probabilities

- Total days = 5
- P(Yes) = 3/5 = 0.6
- P(No) = 2/5 = 0.4

## Step 2: Calculate Likelihoods for the New Features

- Outlook = Sunny:
- P(Sunny | Yes) = 0/3 = 0
  - P(Sunny | No) = 2/2 = 1.0
- Humidity = High:
- P(High | Yes) = 2/3 ≈ 0.67
  - P(High | No) = 2/2 = 1.0

## Step 3: Multiply the Probabilities

- Score for YES:
  $P(\text{Yes}) \times P(\text{Sunny} \mid \text{Yes}) \times P(\text{High} \mid \text{Yes}) = 0.6 \times 0 \times 0.67 = \mathbf{0}$
- Score for NO:
  $P(\text{No}) \times P(\text{Sunny} \mid \text{No}) \times P(\text{High} \mid \text{No}) = 0.4 \times 1.0 \times 1.0 = \mathbf{0.4}$

## Conclusion

Because the No score (0.4) is higher than the Yes score (0), the algorithm classifies this day as No (Will Not Play).
(Note: The score of 0 for "Yes" highlights the Zero-Frequency Problem in Naive Bayes, which is usually resolved in production by adding 1 to every count, known as Laplace Smoothing).
