# K-Nearest Neighbors (KNN)

- K-Nearest Neighbor is a simple & widely used machine learning technique for classification & regression tasks.
- It works by identifying the K closes data point to a given input & making prediction based on the majority class or average value of those neighbors.


The graph maps a new, unlabeled target point at the exact coordinates (5, 6) alongside known historical data split into Class A (Blue) and Class B (Red). A dashed circular boundary centered around the target isolates its 3 closest neighbors: two blue points and one red point. Because Class A holds the majority vote (2 vs. 1), the algorithm officially classifies the new point as Class A.

## How the algorithm works

```
[ New Data Point ]
       │
       ▼
1. Calculate distance to ALL points in the dataset (e.g., Euclidean distance)
       │
       ▼
2. Sort distances and pick the 'K' closest points (neighbors)
       │
       ▼
3. Make a prediction:
   ├── For Classification: Take a Majority Vote (most common label)
   └── For Regression: Take the Average Value of the neighbors
```

## Distance metrics used in KNN algorithm

1. **Euclidean Distance**
   Euclidean distance measures the **straight-line distance** between two points in a geometric space. It represents the shortest possible path if you were to move directly from one coordinate to another.

   `$$d(x, X_i) = \sqrt{\sum_{j=1}^{n} (x_j - X_{ij})^2}$$`

2. **Manhattan Distance**
   Manhattan distance calculates the total distance traveled if you could only navigate along **horizontal & vertical grid lines**. It is often referred to as "taxicab distance" because it mimics how a taxi drives through grid-like city streets.

   `$$d(x,y) = \sum_{i=1}^{n} |x_i - y_i|$$`

3. **Minkowski Distance**
   Minkowski distance acts as a **generalized distance framework** that unifies both Euclidean & Manhattan distances into a single family.

   `$$d(x,y) = \left( \sum_{i=1}^{n} |x_i - y_i|^p \right)^{\frac{1}{p}}$$`

   - When $p = 1$, it becomes **Manhattan Distance**.
   - When $p = 2$, it becomes **Euclidean Distance**.
