# Neural Networks

- **Supervised** ML model inspired by the human brain.
- Made of interconnected neurons organized in layers.
- Learns patterns by **adjusting weights** from data.
- Basis of **Deep Learning** (many hidden layers).

---

## Key terms

| Key Term                | Meaning                                                    |
| ----------------------- | ---------------------------------------------------------- |
| **Neuron (Node)**       | Basic unit: takes inputs, applies weights, outputs a value |
| **Weight (w)**          | Strength of a connection; learned during training          |
| **Bias (b)**            | Offset that shifts the activation                          |
| **Activation Function** | Adds non-linearity (ReLU, Sigmoid, Tanh, Softmax)          |
| **Layer**               | Group of neurons (Input, Hidden, Output)                   |
| **Loss Function**       | Measures prediction error                                  |
| **Epoch**               | One full pass through the training data                    |

```
   x1 ──w1──╲
             ╲
   x2 ──w2────● Σ(wᵢxᵢ) + b ──→ [ f(z) ] ──→ output
             ╱     (sum)        activation
   x3 ──w3──╱
```

Formula: `y = f( w₁x₁ + w₂x₂ + … + wₙxₙ + b )`

## How to Learns

1. **Forward Propagation**: inputs flow through layers to produce output
2. **Compute Loss**: compare prediction with actual value
3. **Backpropagation**: compute gradients of loss w.r.t. weights
4. **Gradient Descent**: update weights to reduce loss
5. **Repeat** for many epochs

```
  Input → [Forward Pass] → Prediction → [Loss]
    ↑                                      │
    └──── [Update Weights] ←── [Backprop] ←┘
```

## Common Activation Functions

```
  ReLU: max(0,x)        Sigmoid: 1/(1+e⁻ˣ)      Tanh
      │    ╱               │   ┈┈┈┈┈             │  ┈┈┈
      │   ╱                │  ╱                  │ ╱
  ────┼──╱────         ────┼─╱────          ────┼╱────
      │                ┈┈┈┈┘ │             ┈┈┈┈╱│
      │                      │                  │
```

| Function    | Range             | Use                     |
| ----------- | ----------------- | ----------------------- |
| **ReLU**    | [0, ∞)            | Hidden layers (default) |
| **Sigmoid** | (0, 1)            | Binary output           |
| **Tanh**    | (-1, 1)           | Hidden layers           |
| **Softmax** | (0, 1), sums to 1 | Multi-class output      |

## Types of Neural Networks

| Type            | Best For                       |
| --------------- | ------------------------------ |
| **ANN / MLP**   | Tabular data, basic tasks      |
| **CNN**         | Images, video                  |
| **RNN / LSTM**  | Sequences, time series, text   |
| **Transformer** | NLP, LLMs, vision              |
| **GAN**         | Image/data generation          |
| **Autoencoder** | Compression, anomaly detection |

## Pros & Cons

| Pros                               | Cons                            |
| ---------------------------------- | ------------------------------- |
| Learns complex non-linear patterns | Needs large data                |
| Automatic feature extraction       | Computationally expensive       |
| Versatile (image, text, audio)     | "Black box" (hard to interpret) |
| Scales with data and compute       | Prone to overfitting            |

## Applications

- Image & speech recognition
- Language translation, chatbots
- Self-driving cars
- Medical diagnosis
- Recommendation systems
