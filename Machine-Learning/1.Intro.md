# Intro Machine Learning

## What is Machine Learning

Machine learning is a **subdomain of computer science** that focus on algorithms which help a **computer learn from data without explicit programming**.

**AI** : Artificial Intelligence is a area of computer science, where the goal is to enable computers & machines to perform human-like tasks & simulate human behavior.
**ML** : Machine Learning is subset of AI that tries to solve a specific problem & make predictions using data.
**DS** : Data Science is a field that attempts to find patterns & draw insights from data (might use ML!).

## Types of Machine Learning

1. **Supervised Learning**: uses labeled inputs (meaning the input has a corresponding output label) to train models & learn outputs.
2. **Unsupervised Learning**: use unlabeled data to learn about patterns in data.
3. **Reinforcement Learning**: agent learning in interactive environment based on rewards & penalties.
