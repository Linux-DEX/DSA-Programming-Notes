## Features

- **Qualitative** - categorical data (finite number of categories or groups)
  - **Nominal(no inherent order)**: categories without any natural order or ranking (e.g, Eye color: blue/green/brown, zip codes, gender, country). You cannot say one is "greater" or "higher" than another.
  - **Ordinal(inherent order)**: categories that do have a meaningful order or ranking (e.g., Education level: high school/bachelor's/PhD, customer satisfaction: low/midium/high).

- **Quantitative** - numerical valued data (could be discrete or continuous).
  - **Discrete**: data that can only take specific, distinct value that you can count (e.g., number of bedrooms: 1,2,3; number of cars). You cannot have 2.5 bedrooms.
  - **Continuous**: data that can take any value within a range & can be measured infinitely (e.g., house price: Rs 10,00,000; temperature; weight).

## Supervised Learning Tasks

1. **Classification**: predict discrete classes (e.g., predicting "spam" vs "not spam", or "cat" vs. "dog").
   - **Binary Classification**: predicting between exactly **two** mutually exclusive categories (e.g., Yes/No, Spam/Not Spam, Fraud/Legitimate).
   - **Multiclass Classification**: predicting between **three or more** distinct categories (e.g., dog/cat/bird, red/blue/green/yellow, rating 1 to 5 stars).

2. **Regression**: predict continuous numerical values (e.g., predicting the exact price of a house, future temperature, or stock price).

## Loss Functions

A Loss Function measures how wrong your model's predicts are compared to the actual target labels. The goal of traning a machine learning model is to minimize this loss value toward 0.

```
  [ Feature Vector x ] ───> [ ML MODEL ] ───> [ Predicted ŷ ]
                                                   │
                                                   ▼
  [ Actual Target y ]  ───────────────────────> [ LOSS FUNCTION ] ───> (Error Score)
```

**L1 Loss (Mean Absolute Error/MAE)**: Calculate the absolute difference between the actual value (y) & the predicted value (ŷ). It scales linearly with error.
**L2 Loss (Mean Squared Error/MSE)**: Calculate the square of the difference between the actual value (y) & the predicted value (ŷ). It scales quadratically with error.

```
       Loss Value
          ^
          │       \             /   <-- L2 Loss (Parabola: Error²)
       9  │        \           /
          │         \         /
       4  │\         \       /         /  <-- L1 Loss (V-Shape: |Error|)
          │ \         \     /         /
       1  │  \_______  \___/  _______/
          │   \      \─/   \─/      /
          └────┴──────┴─────┴──────┴────> Error (y - ŷ)
              -3     -1     1      3
```

| Feature                    | L1 Loss (MAE)                            | L2 Loss (MSE)                                                 |
| -------------------------- | ---------------------------------------- | ------------------------------------------------------------- |
| Mathematical Formula       | $\sum \Vert{}y - \hat{y}\Vert{}$         | $\sum (y - \hat{y})^2$                                        |
| Graph Shape                | V-Shape (Linear)                         | U-Shape (Parabola)                                            |
| Handling Small Errors (<1) | Penalizes them normally                  | Ignores them heavily (squares fractions into smaller numbers) |
| Handling Large Errors (>1) | Penalizes them linearly                  | Penalizes them aggressively (squares big numbers)             |
| Robustness to Outliers     | High (Stays steady when outliers appear) | Low (Explodes and forces the model to fix outliers first)     |

**Binary Cross-Entropy loss** (also known as Log loss) i the standard loss function used for binary classification tasks, where the model must choose between exactly two classes.

```
$$L = - \left( y \log(\hat{y}) + (1 - y) \log(1 - \hat{y}) \right)$$
```

Where:

- \(y\) / \(y_i\) is the **Actual Target Label** (strictly `0` or `1`).
- \(\hat{y}\) / \(\hat{y}_i\) is the **Predicted Probability** (a float value between `0.0` and `1.0`).
- \(N\) is the total number of samples in the dataset.
