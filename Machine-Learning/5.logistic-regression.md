# Logistic Regression

Logistic Regression is one of the most fundamental & popular supervised machine learning algorithms. Despite having "regression" in it's name, it is primarily used for classification tasks predicting which category an input belongs to.

```text
   ╭──────────────────────────────────────────────────────────╮
   │   LOGISTIC REGRESSION  ·  P(y=1 | x) = σ(wᵀx + b)       │
   ╰──────────────────────────────────────────────────────────╯

   INPUT          LINEAR            SIGMOID           OUTPUT
   ─────          ──────            ───────           ──────

   x₁ ──╮
        │ w₁
   x₂ ──┤ w₂       ╭───────╮        ╭───────╮
        ├────────▶ │   Σ   │ ─ z ─▶ │ σ(z)  │ ─ p ─▶  ŷ = 1  if p ≥ 0.5
   x₃ ──┤ w₃       │ wᵀx+b │        │  1    │              0  otherwise
        │ ⋮        ╰───────╯        │ ───── │
   xₙ ──╯ wₙ           ▲            │ 1+e⁻ᶻ │
                       │            ╰───────╯
                    󰐕 bias b
```

## Types

1. **Binomial Logistic Regression**: Used when the dependent variable has only two possible categories, such as Yes/NO, Pass/Fail or 0/1. It is the most common type & is used for binary classification tasks.
2. **Multinomial Logistic Regression**: Used when the dependent variable has three or more unordered list categories. e.g., classifying animals as cat, dog or sheep. It extends logistic regression to handle multiple classes.
3. **Ordinal Logistic Regression**: Used when the dependent variable has three or more categories with a natural order,such as low, medium, & high. It considers the ranking of categories during prediction.

## Assumptions

1. Independent Observations
2. Binary Dependent Variable
3. Linearity of Log-Odds
4. No Exterme Outliers
5. Large Sample Size

```text
   x₂
    ▲
    │  ○   ○        ╲
    │    ○    ○      ╲        ●   ●
    │  ○   ○   ○      ╲     ●   ●

    └──────────────────────╲─────────────▶ x₁

        ○ = class 0       ● = class 1
```

## Training Pipeline

```text
   ╭────────╮   ╭─────────╮   ╭─────────╮   ╭──────────╮   ╭──────────╮
   │  Data  │──▶│ Forward │──▶│  Loss   │──▶│ Gradient │──▶│  Update  │
   │ (X, y) │   │ p = σ(z)│   │ BCE     │   │ ∂L/∂w    │   │ w ← w-η∇ │
   ╰────────╯   ╰─────────╯   ╰─────────╯   ╰──────────╯   ╰────┬─────╯
                    ▲                                           │
                    ╰────────────  repeat until converge  ◀─────╯
```

## 󰊕 Key Formulas

| Component | Formula |
|---|---|
|  **Linear** | `z = wᵀx + b` |
| 󰘧 **Sigmoid** | `σ(z) = 1 / (1 + e⁻ᶻ)` |
| 󰀪 **Loss (BCE)** | `L = -[y·log(p) + (1-y)·log(1-p)]` |
| 󰁔 **Gradient** | `∂L/∂w = (p - y)·x` |
| 󰑓 **Update** | `w ← w - η · ∂L/∂w` |
